# Kanishk Prasad — Developer Portfolio

Personal portfolio website for [Kanishk Prasad](https://github.com/Kanishkp2906), a Python Developer & AI Engineer building high-performance backends and intelligent workflows.

## Tech Stack

- [Next.js](https://nextjs.org/) 16 (App Router) + React 19
- [TypeScript](https://www.typescriptlang.org/)
- [Tailwind CSS](https://tailwindcss.com/) v4
- [shadcn/ui](https://ui.shadcn.com/) + [Base UI](https://base-ui.com/)
- [lucide-react](https://lucide.dev/) icons
- [Vercel Analytics](https://vercel.com/analytics)

## Sections

- **Hero** — introduction and roles
- **Tech Stack** — languages and tools
- **Projects** — selected work (MarketPulse Dashboard, Groundwork CLI, AMZ Price Tracker)
- **About** — background and photo
- **Contact** — GitHub and social links

## Getting Started

```bash
npm install     # or pnpm install
npm run dev     # start the dev server at http://localhost:3000
```

## Scripts

| Command            | Description              |
| ------------------ | ------------------------ |
| `npm run dev`      | Start the dev server     |
| `npm run build`    | Production build         |
| `npm run start`    | Serve the production build |
| `npm run lint`     | Run ESLint               |

## Project Structure

```
app/          # Next.js App Router (layout, pages, resume)
components/   # UI components (hero, projects, about, contact, ...)
lib/          # Shared utilities
public/       # Static assets
pictures/     # Local images
```
