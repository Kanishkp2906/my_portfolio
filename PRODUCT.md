# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

Next.js 16, React 19, Tailwind CSS v4, TypeScript. Deployed on Vercel.

## Users

Primary: Hiring managers and technical leads at mid-to-large tech companies looking for backend/AI engineers. They scan quickly for: shipped production systems, depth in Python/FastAPI, AI/ML integration experience, infrastructure competence, and clear communication.

Secondary: Peer engineers evaluating technical depth; recruiters matching keywords.

## Product Purpose

A portfolio that proves Kanishk can architect and ship production-grade backend systems and AI workflows — not just demo projects. It demonstrates technical depth through real, deployed systems with live demos and source code.

Success = qualified inbound conversations for full-time backend/AI engineering roles.

## Positioning

Unlike typical portfolios that list technologies, this one shows *systems thinking*: each project exposes the architectural decisions (caching strategy, queueing, data modeling, rate limiting) that make it production-ready. The mechanism is "show the hidden layer" — the parts users never see but engineers respect.

## Operating Context

Visitors arrive from: LinkedIn profile, GitHub profile, direct link in applications, search. Session duration target: 60-90 seconds. Key conversion: clicking "Source" or "Live Demo" on a project, or the "Hire Me" CTA.

Viewed primarily on desktop (technical audience), but mobile must be flawless for recruiter quick-scans.

## Capabilities and Constraints

- Three real, deployed projects with live demos and GitHub repos
- Resume available as PDF download
- Contact via email, GitHub, LinkedIn, X
- Analytics via Vercel Analytics (production only)
- No CMS — content is code
- Dark-mode only (intentional, technical audience)
- Must remain fast, accessible, SEO-friendly

## Brand Commitments

Name: "Kanishk Prasad" (fixed)

Current accent: #A79DFD (lavender) — can evolve but keep in the cool/purple family
Fonts: Geist (sans), Geist Mono (mono), Playfair Display (accent) — can evolve with rationale
Tone: Precise, confident, not marketing-fluff

## Evidence on Hand

- 3 shipped projects with screenshots, live URLs, GitHub repos
- Resume PDF (Google Drive link)
- Profile photo
- No testimonials, no client logos, no metrics dashboards — future work must not fabricate these

## Product Principles

1. **Show the architecture, not the stack** — technologies are table stakes; decisions are signal
2. **Respect the viewer's time** — scannable, no fluff, every element earns its place
3. **Production evidence > claims** — live demos, source links, real constraints discussed
4. **Technical craft in the portfolio itself** — the site demonstrates the same care as the work it shows
5. **Dark, fast, accessible** — the baseline for a backend engineer's portfolio

## Accessibility & Inclusion

WCAG 2.1 AA target. Reduced motion respected. Semantic HTML. Focus management. Color contrast in dark mode. Keyboard navigable.
